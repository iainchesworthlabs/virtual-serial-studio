Before you install

Windows
Windows 10 or 11, 64-bit. The installer carries Studio's own COM port driver, which is test-signed: Windows accepts it only on a machine where the Iain Chesworth Labs certificate authority has been installed. On any other machine the installer skips the driver and installs the rest, and Studio still shares real devices, bridges to the network and monitors. A driver signed through Microsoft is part of the Pro edition, which is in development.
Linux
x86-64. Use the package for your distribution, or the archive on any other. Virtual ports are pseudo terminals, so no driver is needed. Your account needs permission to open a real serial port, and the user guide says how to grant it.
macOS
Apple silicon. Open the disk image and drag Studio to Applications. The app is not yet signed or notarised by Apple, so macOS will ask you to confirm before it opens. Virtual ports are pseudo terminals, so no driver is needed.
Build it yourself
The source of the application, the command line tool and the driver is in the repository on GitHub, with instructions for each system in the documentation.

Check what you downloaded

Each file has a detached OpenPGP signature beside it, ending .asc. SHA512SUMS lists a checksum for every file and is signed as well.

  1. Get the release key. Download the public key from this site and import it. Then compare its fingerprint with the one below and with the one in SECURITY.md in the repository. A key that arrives with a download proves nothing by itself.
  2. Verify the signature. Put the file and its .asc in the same folder and ask GnuPG to check them.
  3. Or verify the checksums. Verify SHA512SUMS with its signature, then check your file against it.
gpg --import signing-key.asc
gpg --fingerprint FD13CB8CAC8316648CD974D08149254C41894DBE
gpg --verify FILE.asc FILE

gpg --verify SHA512SUMS.asc SHA512SUMS
sha512sum --check --ignore-missing SHA512SUMS

The release key is Iain Chesworth Labs Releases, Ed25519, with the fingerprint FD13 CB8C AC83 1664 8CD9 74D0 8149 254C 4189 4DBE. Each file also has a GitHub build-provenance attestation.

Put the name of the file you downloaded in place of FILE. On Windows, certutil -hashfile FILE SHA512 prints a checksum to compare by eye.
