**Releases come as packages for Linux, macOS and Windows, with checksums, signatures and provenance.** A `vMAJOR.MINOR.PATCH` tag builds `vss_gui` with the Qt libraries it needs and `vss_cli` for Linux (x86_64), macOS (Apple silicon) and Windows (x86_64), runs the command line tool from the installed tree, and publishes them with `SHA512SUMS`, a detached GPG signature for every file, an SPDX software bill of materials and a build provenance attestation for every package. The Windows programs are signed when the release is built with signing on, and each package says in its name whether they are (`-unsigned` or `-testsigned`). `SECURITY.md` says how to report a vulnerability privately and how to check a download against the release signing key, which is committed as `docs/signing-key.asc`. The macOS app is not signed or notarised yet, so Gatekeeper asks you to allow it. The Linux package needs glibc 2.42 or newer (Ubuntu 26.04 or later) and the system's xcb libraries; `docs/releasing.md` lists them.
