**Releases come as packages for Linux, macOS and Windows, with checksums, signatures and provenance.** A `vMAJOR.MINOR.PATCH` tag builds `vss_gui` and `vss_cli` for Linux (x86_64), macOS (Apple silicon) and Windows (x86_64), and publishes them with `SHA512SUMS`, a GPG signature for every file, an SPDX software bill of materials and a build provenance attestation. Each package name says whether the Windows programs are signed (`-unsigned` or `-testsigned`). `SECURITY.md` says how to report a vulnerability privately and how to check a download against the release signing key, `docs/signing-key.asc`. The macOS app is not signed or notarised yet, so Gatekeeper asks you to allow it. The Linux package needs glibc 2.42 or newer (Ubuntu 26.04 or later); `docs/releasing.md` lists the rest.
