**Set up Virtual Serial Studio reports what failed, and no longer stops on a driver that is already up to date.**
- When the helper service could not be installed or started, the script ended with code 1 and Studio said "Setup did not finish". It now ends with code 8 and Studio says the driver is installed and only the helper is left. The same holds for `remove-driver.ps1`, `install-helper.ps1` (code 2 when not run as an administrator) and `install-trust.ps1` (codes 2 and 3), whose documented exit codes could not be reached before.
- When `pnputil` answers 259 (no device was updated because the devices already use this driver or a newer one), set-up goes on if the driver store holds this version of the package. Before, it stopped with code 7 and did not touch the helper.
- A package whose signature is valid but whose signer is not in Trusted Publishers (and is not signed by Microsoft's hardware publisher) is refused with code 6 before `pnputil` is started. Before, a silent install waited for a question that nobody could answer until `pnputil` was stopped, and ended with code 7.
