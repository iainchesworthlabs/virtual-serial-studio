**Reading one port, the links, and ping and session.close through the control endpoint.** A program or `vss_cli` can now read one port or one link by its id and list the links alone, which needs the scope `monitor`, and can ask whether the gateway answers and end its own session, which need no scope. `vss_cli control port show <id>`, `vss_cli control links`, `vss_cli control link show <id>` and `vss_cli control ping` print the answers, and the Python client has `get_port`, `list_links`, `get_link` and `ping`. An id that is not of the form `p_3` or `l_2` is refused as `invalid_argument`, and one that nothing has is `not_found`.
