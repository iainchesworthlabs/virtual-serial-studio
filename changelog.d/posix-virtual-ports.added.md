**Virtual serial ports on Linux and macOS, with names that stay the same.** Studio makes pseudo terminals that other programs open like any serial port. `vss_cli vport --name=ttyVSS0,ttyVSS1 --link=ttyVSS0:ttyVSS1` creates a port for each name, prints the stable link a program should open (such as `$XDG_RUNTIME_DIR/vss/ttyVSS0`), joins linked pairs like a null-modem cable, and runs until Ctrl-C or SIGTERM, when it removes its links. The Ports list shows these virtual ports, and on Linux it shows **Waiting for program** until a program opens the port and **Program connected** once one does.
