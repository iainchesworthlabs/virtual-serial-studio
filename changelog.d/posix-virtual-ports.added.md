**Virtual serial ports on Linux and macOS, with names that stay the same.** Studio makes pseudo terminals that other programs open like any serial port. `vss_cli vport --name=ttyVSS0,ttyVSS1 --link=ttyVSS0:ttyVSS1` creates a port for each name, prints the stable link a program should open (such as `$XDG_RUNTIME_DIR/vss/ttyVSS0`, which always points at the pseudo terminal's current `/dev/pts/N`), joins linked pairs like a null-modem cable, and runs until Ctrl-C or SIGTERM, when it removes its links. A link left by a process that was killed is replaced the next time, and a name that a running process holds is refused. The links directory is created closed to everyone but its owner. The Ports list shows these virtual ports (and USB gadget, `tnt` and Bluetooth serial devices), and on Linux it shows **Waiting for program** until a program opens the port and **Program connected** once one does. `auto` virtual ports choose a pseudo terminal on both systems.
