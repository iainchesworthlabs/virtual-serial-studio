**The plugin host can start a plugin's generator on a port and write its bytes there.** For each running generator instance the host asks the owner of the ports for the port its parameters name, sends `generator.start`, gives the plugin its credit, and writes what the plugin sends to that port. Credit goes back only as the port takes bytes, so a slow port stops the plugin and the host never holds more than the window. A write the plugin may not send is refused and counted, and a generator that keeps doing it is stopped. Patterns are not made yet. Nothing in Studio uses this yet.
