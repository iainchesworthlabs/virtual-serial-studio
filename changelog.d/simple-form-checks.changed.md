**Simple view: device settings, COM numbers and network addresses in the forms are applied and checked.** The speed and other settings chosen with **Change** now reach a device that stays open, including one over RFC 2217, and Apply says it cannot do that where a build has no way to. Devices are opened first, so a busy device is found before a port is installed, and Automatic can no longer take a COM number that another row of the same form chose. A network address accepts a name or address, `host:port`, an IPv6 address with or without brackets, and `tcp://` or `rfc2217://` in front. An address that cannot be used stops Create and says how an address is written.
