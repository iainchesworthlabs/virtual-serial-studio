**The user guide has a Licences section.** It explains the licence file and Help, Licence, how to import a licence, where licence files are kept, and what happens when a licence ends, is renewed or is removed. It also says what to do when the date on the computer looks wrong, and that this version trusts no licence key yet, so every build is the Community edition. The release now carries its own revocation list, which is empty. A signed list in a licence folder replaces it only when its sequence number is higher.
