**A Python client for the control endpoint.** `adapters/python` holds `vss_control`, a client for the gateway that needs Python 3.9 and no other package, so a test script can make and link ports, send bytes, wait for a pattern with `expect_bytes`, read the event and traffic streams, and keep a run and its JUnit report. It uses the same named pipe or Unix socket as `vss_cli control`, takes a token as text or from a file, and gives each call a time limit. It first checks that the endpoint is served by the user who runs the script.
