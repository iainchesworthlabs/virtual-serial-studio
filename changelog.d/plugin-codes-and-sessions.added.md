**A plugin can show you a code and ask for a remote control session.** When a running plugin has a pairing code or a one-time password for you, Studio shows it once in a dialog with the plugin's name and a countdown, and keeps it nowhere: not in the log, not on the Plugins page, not in a file. **Copy** is the only way it reaches the clipboard. When a plugin asks to use Studio's remote control, Studio asks you first: it shows who the session is for and why, what it could do (marking what lets the other side see or send data), and how long it would last. Refuse is the default, and nothing is remembered. A plugin that was granted it can also record the traffic of your ports and links into its own folder, replay data into a port, and decode the traffic of the ports and links you name; what a decoder finds is shown on the Plugins page. The Plugins page also lists what Studio runs of each plugin, with **Add...** and **Remove**, shows what a plugin said about its licence check, and says when a plugin changed after you decided about it. A plugin that reads your licence file sees your name, and the approval question says so.
