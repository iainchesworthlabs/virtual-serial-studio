**Closing the Studio window does not stop the ports.** Studio stays in the notification area and keeps them running until you quit it, and starting Studio again brings back the same window. The running setup is kept by itself and starts again after a restart, a sign-out or a crash, and after a Quit a banner offers to start it again. **Settings, Running** can make closing quit instead, and (on Windows and Linux) start Studio hidden when you sign in.
