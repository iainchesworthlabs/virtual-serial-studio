**Studio checks that a Windows PC is set up for virtual COM ports, and sets it up in one step.** The first screen, the Setup check and the error of a port that could not be made say which piece is missing (the driver, the helper service, a stopped or out-of-date helper, or a helper that refuses your account) and offer one action, **Set up Virtual Serial Studio**. It installs or repairs the driver and helper through one Windows permission prompt, using the files that come with Studio; nothing is downloaded and no certificate is added. It checks the signatures first and installs nothing when Windows does not trust them, which is the case for an unsigned or test-signed build on a machine that does not trust its certificate (`drivers/windows/README.md` says what each build shows). An error never says only "permission denied": each cause has its own message with the next step and the call that failed behind **Copy details**. Studio counts either its own driver or com0com as a virtual port driver, and says which one it found.
