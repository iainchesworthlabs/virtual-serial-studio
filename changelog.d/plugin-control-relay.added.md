**The plugin host has a control relay, so the remote control plugin can use the control gateway without holding a token.** When a plugin asks for a session, the host asks you to approve the scopes, makes a token with exactly those scopes through the gateway's administration endpoint, connects to the gateway's local pipe or socket as that token and passes the plugin's frames both ways unchanged. The plugin never sees the token or opens a connection, a frame that says `hello` is refused, and each session has its own token, which the host revokes when the session ends or the plugin stops or fails. Nothing in Studio uses the relay yet.
