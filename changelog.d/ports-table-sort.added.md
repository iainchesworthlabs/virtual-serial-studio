**The Advanced Ports table can be sorted.** Click a column heading to sort by it, click again to reverse, and a third time to go back to the order Studio keeps. `Ctrl+Alt+S` does the same from the keyboard with the cursor in a column. The arrow on the heading shows the order, which is kept for the next start. State sorts failed first, then waiting, open, connected, Studio only, fixture and closed, with a port you stopped last. A value Studio does not know for a port always sorts last. A sorted table keeps the selected port and its scroll position while counts change and rows move.
