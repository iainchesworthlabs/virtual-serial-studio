**A COM number that a removed Studio port used can be used again.** On Windows, Change COM number refused a number such as COM1 that a Studio port had held and that you had since deleted, with "COM1 already belongs to a device". Windows keeps the entry of a removed port and the number with it. Studio now clears the entry of a removed Studio port, and a number that only Windows' list marks with no device behind it, when you ask for that number. A number that a connected device holds, or that an unplugged device of another kind keeps for when it returns, is still refused.
