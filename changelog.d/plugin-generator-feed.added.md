**The plugin host has the rules for a generator.** A plugin that produces bytes is given credit, and a batch it sends beyond that credit, beyond the size limits, out of order or at the wrong time is refused and counted; enough refusals end it. Batches are written to the port never before their time, and credit is given back only as the port takes bytes, so a slow port can never make the host hold more than the window. Generators use it.
