**Studio checks that this PC is set up for virtual COM ports, and sets it up in one step.** On Windows the first screen, the Setup check and the error of a port that could not be made now say which piece is missing (the driver, the helper service, a stopped or out-of-date helper, or a helper that refuses your account) and offer one action, "Set up Virtual Serial Studio". It installs or repairs the driver and the helper through one Windows permission prompt, using the files that come with Studio (`drivers/windows/setup-driver.ps1`); nothing is downloaded and no certificate is added. It checks the signatures first and installs nothing when Windows does not trust them, which is the case for an unsigned or test-signed build on a machine that does not trust its certificate; `drivers/windows/README.md` says what each kind of build shows. `vss::probe_driver_setup()` asks each piece without making a port, and `vss::last_driver_failure()` keeps the call that failed.
