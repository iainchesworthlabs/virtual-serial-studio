**Settings, About and licences.** **Settings** (Ctrl+,) holds Advanced mode, theme, density, refresh interval, default baud rate and whether to ask before discarding an unsaved setup; each applies at once. **About** shows the GPL-3.0-or-later notice and no-warranty statement, the version and build, and an Environment tab (commit, compiler, Qt and Boost versions, operating system, architecture, language) written to be copied into a bug report, plus Licences for everything Studio is built from; no fonts are bundled. Virtual Serial Studio is released under the GNU General Public License, version 3 or later; Boost.VirtualSerial, Boost and the tools derived from them keep their own licences (`THIRD_PARTY_NOTICES.md`). The repository passes `reuse lint`. For performance work, Tracy zones cover the engine, every transport, the CLI and the GUI and are compiled in, but dormant, in release builds; **Settings, Performance, Profiling**, `--profile` or `VSS_PROFILE=1` turns them on, and the listener binds to 127.0.0.1 unless `--profile-remote` is given (`docs/profiling.md`).
