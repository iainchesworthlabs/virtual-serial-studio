**Adding a plugin whose description file is refused now says what is wrong.** When Studio could not use a plugin because of its `plugin.json`, **Plugins > Add a plugin...** showed only "Its description file is not valid, so Studio cannot tell what it is." It now adds the line from Studio's check, for example "What is wrong: an official plugin must have not_after". This is how the Remote control and monitoring plugin of release candidate 6 was refused.
