**An `rfc2217://host:port` port now sets the speed, DTR, RTS and break on the server.** Studio's own RFC 2217 client opens the connection and sends the speed and framing in the address (`?baud=115200&data=8&parity=none&stop=1`) as the server agrees to the COM-PORT option. A change of DTR or RTS reaches the server, and the server's CTS, DSR, DCD and RI are shown as the port's inputs. A break that arrives at the port is sent to the server as break on, a wait of its length and break off, and the log says that the length on the wire is only as accurate as the network. A break the server reports (a notice with the break bit of the line state) is a break in the stream, in order with the bytes around it, and its length is one character time because the server does not say it. A server that does not offer RFC 2217 is used as a plain byte stream, and the log says so.
