**The Windows installer closes a Studio that is running, and an uninstall no longer leaves start at sign-in behind.** An upgrade over a running Studio could not replace `vss_gui.exe`, and an uninstall left the folder. Both now close `vss_gui.exe` and `vss_cli.exe` when they run from the install folder; the ports start again the next time Studio is opened. An uninstall also removes the **Start when I sign in** entry of every signed-in user and records in each user's running setup that the ports were stopped, so a Studio that is installed again offers them with **Start again** and does not start them by itself.
