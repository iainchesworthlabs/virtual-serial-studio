**Studio runs the plugins you switch on.** A plugin that you have decided about and switched on starts as a program of its own, apart from Studio, in the sandbox this computer can give it, and the Plugins page shows its state as it changes: Starting, Starting again in a number of seconds (attempt 3 of 5), On, or Stopped after failing with **Start again**. The Isolation row says how much of the sandbox was applied and what is missing, and the plugin's own status text and messages are shown as plain text. Plugins are stopped, each asked first, when Studio closes. A plugin that is not official and cannot be kept apart on this computer runs only if you choose **Run without isolation...** for that version.
