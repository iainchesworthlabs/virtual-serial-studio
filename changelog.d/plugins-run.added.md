**Studio runs the plugins you switch on.** A plugin that you have decided about and switched on starts as a program of its own, apart from Studio, in the sandbox this computer can give it. The Plugins page shows its state: Starting, Starting again in a number of seconds (attempt 3 of 5), On, or Stopped after failing with **Start again**. Plugins are stopped when Studio closes. A plugin that is not official and cannot be kept apart runs only if you choose **Run without isolation...** for that version.
