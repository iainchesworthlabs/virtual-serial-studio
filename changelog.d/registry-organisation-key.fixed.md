**Settings no longer sit under a doubled registry key.** On Windows Studio kept its settings in `HKCU\Software\Virtual Serial Studio\Virtual Serial Studio`, because the organisation and the application had the same name. They are now in `HKCU\Software\iainchesworthlabs\Virtual Serial Studio`, beside the ARINC Data Loader, and the saved running setup is in `%APPDATA%\iainchesworthlabs\Virtual Serial Studio`. On Linux and macOS the configuration files move from `Virtual Serial Studio/Virtual Serial Studio` to `iainchesworthlabs/Virtual Serial Studio` in the same way. Settings made in earlier builds are not carried over.
