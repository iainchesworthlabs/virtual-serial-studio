**About shows the full build and splits it from the environment.** The header and `--version` now show one version string such as `v0.1.0-rc.3+build.6083-3de4617`. A new **Build information** tab lists the version, Git tag, revision, branch, build number and time (UTC), build type, compiler and the Qt and Boost it was built with. **Environment** now holds only the computer: operating system, architecture, display, language and profiling. Each tab has its own copy button, and **Copy diagnostic information** (in About and the Help menu) copies both. **Licences** lists only what the build contains, read from `third_party.json`; the com0com driver, which you install yourself, is no longer listed.
