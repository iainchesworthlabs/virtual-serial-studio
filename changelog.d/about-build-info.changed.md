**About shows the full build and splits it from the environment.** The header and `--version` now show one version string such as `v0.1.0-rc.3+build.6083-3de4617`: the release, the CI run number and the short commit. A new **Build information** tab lists the version, Git tag, full and short revision, whether the tree was modified, the branch (the real branch or tag, not "HEAD"), the build number, the build time in UTC, the build type, the compiler and the Qt and Boost it was built with. **Environment** now holds only the computer: operating system, architecture, kernel, Qt running, platform plugin, display size and scale, language and profiling. Each tab has its own copy button, and **Copy diagnostic information** (in About, the Help menu and the diagnostic bundle dialog) copies both; `environment.txt` in the bundle holds both. **Licences** lists only what the build contains, read from `third_party.json`: Qt, Boost and Boost.VirtualSerial, and Tracy only in a build with the profiler. The com0com driver, which you install yourself and which is not part of Studio, is no longer listed. **Fonts** is read from the same file and lists any bundled font family with its licence.
