- **Traffic no longer changes what is selected.** The Ports pane used to select the first port whenever no port was selected, so selecting a link on the canvas while data flowed also selected the first port, and Delete then removed that port as well. It now selects the first port once, when a setup first shows, and a refresh never changes the selection after that.
- **The Send pane's "Sending from:" line follows the selected port.** It used to keep the name of the port that was selected before.
- **Switching the Monitor between text and hex with a search typed keeps the table and the export the same.** The search is matched against the text now shown, the table is rebuilt when the view changes, and the export writes the rows in the table.
