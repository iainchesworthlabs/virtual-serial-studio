**A silent install of Studio on Windows no longer waits for ever when the driver's signer is not trusted.** With Windows test signing on, `setup-driver.ps1` accepted a package signed by a publisher the machine did not trust and passed it to `pnputil`, which then asked "Would you like to install this device software?" with nobody to answer. The set-up now accepts a package only when Microsoft's hardware publisher signed it or its signer is in Trusted Publishers (`trust\install-trust.ps1`); otherwise it ends as "not trusted" with nothing changed.
