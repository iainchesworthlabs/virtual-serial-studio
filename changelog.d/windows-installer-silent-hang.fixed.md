**A silent install of Studio on Windows no longer waits for ever when the driver's signer is not trusted.** With Windows test signing on, `setup-driver.ps1` accepted a package that was signed by a publisher the machine had not been told to trust and passed it to `pnputil`, which then asked "Would you like to install this device software?" on a desktop nobody could answer. The set-up now accepts such a package only when its signer is in Trusted Publishers (`trust\install-trust.ps1`), otherwise it ends as "not trusted" with nothing changed, and every `pnputil` call and the whole of `setup-driver.ps1` and `remove-driver.ps1` have time limits.
