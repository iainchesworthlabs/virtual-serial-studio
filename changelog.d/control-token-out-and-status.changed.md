**`vss_cli control token create --out` makes a private file first, and `status` says only what it knows.** `--out=<file>` now needs a name that is not a file yet: the file is made first, empty, and only you can read it. When the file cannot be made, `token create` makes no token, and when the token cannot be written to it, the token is revoked and the file is removed. A token that names a transport twice is refused. `vss_cli control status` says `Remote control: on` and whether it reached the gateway over the local pipe or socket or over TCP. `run begin` and `run record` cut a name of more than 128 bytes and a message of more than 512 to that length.
