**Windows has an installer that sets up the virtual COM port driver.** The release holds `virtual-serial-studio-<tag>-windows-x86_64.exe` beside the zip. It installs Studio and the command line tool for all users in `Program Files\Virtual Serial Studio`, adds a Start menu entry and an uninstaller, replaces an earlier version on upgrade, and can put the folder of `vss_cli` on the system PATH (off unless you tick it or give `/ADDTOPATH=1`; the uninstaller takes it out again). A ticked box also installs the user-mode virtual COM port driver and its helper service (`/S /DRIVER=0` skips them in a silent install); the uninstaller removes both. The installer adds no certificate and does not turn on test signing: when Windows does not trust the signature on the driver files, Studio is installed anyway, the driver is not, and the installer says why and what to do (`bin\driver\trust\install-trust.ps1`, then **Set up Virtual Serial Studio**). The kernel-mode driver is not included.
