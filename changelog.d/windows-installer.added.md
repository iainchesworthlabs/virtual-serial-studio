**Windows has an installer.** The release now holds `virtual-serial-studio-<tag>-windows-x86_64.exe` beside the zip. It installs Studio and the command line tool for all users in `Program Files\Virtual Serial Studio`, adds a Start menu entry and an uninstaller to Apps & features, replaces an earlier version when you upgrade, and can put `vss_cli` on the PATH (off unless you tick it). It is signed the way the programs in it are, and the release workflow installs it silently, runs both programs from the installed folder and uninstalls it before the file is published. The virtual COM port driver and its helper service are not in it yet, because they are not signed for production; `docs/releasing.md` says what is left.
