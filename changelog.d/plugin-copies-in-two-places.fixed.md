**The Plugins page is clear about a plugin that is installed in two places.** Adding a plugin that is already installed no longer shows a message with no name in it: it says which plugin, and where the installed copy is. When a copy is installed for everyone on the computer, or came with Studio, that copy runs, so Studio no longer adds a second copy for you only that could never run; it says so and tells you to ask your administrator. A copy that is not used says which copy runs instead and whether it is installed for everyone or came with Studio, and the copy that runs says where it is installed. Removing your own copy now removes that copy even when the copy for everyone is identical, and leaves the other copy listed and running, with its saved settings and data.
