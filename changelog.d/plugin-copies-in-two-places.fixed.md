**The Plugins page is clear about a plugin that is installed in two places.** Adding a plugin that is already installed now says which plugin, and where the installed copy is. When a copy is installed for everyone on the computer, or came with Studio, that copy runs, so Studio no longer adds a second copy for you only that could never run; it tells you to ask your administrator. Removing your own copy now removes that copy even when the copy for everyone is identical,.
