**Set up Virtual Serial Studio works from Windows PowerShell 5.1.** `setup-driver.ps1` and `install-helper.ps1` took their folder from `$PSScriptRoot` in a parameter default, which Windows PowerShell 5.1 leaves empty when the script is started with `-File`, as Studio starts it. The script stopped with "Cannot bind argument to parameter 'Path' because it is an empty string" before it changed anything. The default is now set in the body, and `install-helper.ps1` takes Program Files from `ProgramW6432`, so the helper lands in the 64-bit Program Files when a 32-bit program starts it.
