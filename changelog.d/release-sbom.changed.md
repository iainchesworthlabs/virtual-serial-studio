**The software bill of materials of a release lists what the packages hold.** `sbom.spdx.json` names Qt, Boost, Boost.VirtualSerial, Monocypher and the three bundled fonts with their versions and licences, so a vulnerability scanner can match them. It no longer lists the GitHub Actions of the build or Tracy, which the packages do not contain. The file is in `SHA512SUMS` with the packages, and the Debian package of a pre-release has a `.` where its version has the `~` in its file name, so `sha512sum -c SHA512SUMS` finds every file.
