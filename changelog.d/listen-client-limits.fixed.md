**A listening port has limits on what a client can make it do.** It accepts up to 32 clients at once and closes any more as soon as they connect, with a note in the log (at most one every 10 seconds). When the computer cannot accept a connection, for example because the program has used up the open connections and files the system allows it, the port waits 100 ms and then longer, up to 5 seconds, before it tries again, and says so in the log, instead of using a whole processor. An RFC 2217 client that sends requests and does not read the replies is disconnected when its replies reach 1 MiB instead of growing memory without end. Connections now use TCP keep-alive, so the system will in time notice a client whose computer has gone.
