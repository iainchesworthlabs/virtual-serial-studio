**Every build says which commit it was made from, and so does every plugin.** The version in About, in `vss_cli --version` and in the diagnostic information now reads like `v0.1.0-rc.5+18.g7d42b4e.build.6083`: the release, the number of commits after its tag, `g` and the short commit, the CI run number, and `.dirty` when the tree was modified. A plugin's `version` may carry the same build metadata after a plus sign, such as `0.1.0+57.g7ffbece`. The Plugins list and `vss_cli plugin list` show it. `tools/plugin_sign.py` signs a manifest with such a version.
