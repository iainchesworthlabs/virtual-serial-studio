**Saving a setup no longer empties your file before the new text is written.** The setup is written to a new file beside yours, checked, and then put in place of the old file in one step. If the disk is full, the write fails or Studio is stopped during a save, you get an error and your file is as it was. Nothing is forced to the disk, so a power cut during or just after a save can still leave the file empty or part written.
