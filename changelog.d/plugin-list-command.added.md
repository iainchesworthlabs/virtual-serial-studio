**`vss_cli plugin list` shows the plugins that are installed.** For each plugin it prints the id, version and name, the folder, who it is installed for (everyone on this computer, you only, or came with Studio), a fingerprint of its files, whether it has a `plugin.sig`, and either `found` or the reason it cannot be used. It also says whether Studio is installed for everyone or for you only. `--json` prints one JSON object, and `--root <folder>` looks in the folders you give. The command only reads. It runs no plugin. Its findings are those of `vss_cli plugin verify`.
