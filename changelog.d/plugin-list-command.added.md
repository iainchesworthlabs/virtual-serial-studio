**`vss_cli plugin list` shows the plugins that are installed.** For each plugin it prints the id, version and name, the folder, who it is installed for (everyone on this computer, you only, or came with Studio), a fingerprint of its files, whether it has a `plugin.sig`, and either `found` or the reason it cannot be used. It also says whether Studio is installed for everyone or for you only, and whether an administrator's policy file is in use. `--json` prints the same as one JSON object, and `--root <folder>` looks in the folders you give instead of the usual ones. Plugins are looked for in `studio-plugins` next to Studio's `bin` folder, in a machine folder and in your own folder; the user guide lists them for each system. The command only reads. This build does not run plugins and does not check signatures.
