**New library calls `hub::add_target` and `hub::remove_target`** add one target to a two-way link or a split, or take one off, without touching the others. They refuse a one-way link or a bus (`unsupported`), the link's source (`invalid_argument`), a target that is there already (`already_exists`), a loop (`cycle_detected`), and taking off the last target (`invalid_argument`; remove the link instead). Taking off the target that owns the link releases the owner.
