**The plugin host can confine a plugin on Windows.** A plugin started with a sandbox profile runs in a job object and an AppContainer of its own: it can read its own folder and write its data folder and reach no other file of yours, it has no network unless that was granted, it cannot open other programs, it has no window or clipboard, and it is held to limits on memory, processes and processor time. A start reports which of these parts were applied, and can refuse to start anything when the computer cannot apply enough. Linux and macOS do not confine a plugin yet and say so. Nothing in Studio starts a plugin yet.
