**On Windows, choose the COM number of a port, and change it later.** Ask for it when the port is made (**Add port** has a **COM number** field, `vss_cli virtual --com=7`, or `"com_number": 7` in a saved topology) or change it from the Inspector's **Change...** button, as Device Manager does. Programs that open a fixed name such as `COM3` then find the same port every run. A number another device has, a real port, com0com or anything else is refused beside the field in words that say what to do, and nothing is changed. Without a chosen number, a new port takes a number above every port the computer already has and never below COM3, so a program set up for an on-board COM1 or COM2 does not find one of ours. Choosing a number needs the helper service.
