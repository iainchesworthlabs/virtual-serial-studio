**Check, install and remove a plugin from the command line.** `vss_cli plugin verify <folder>` makes the checks that come before a plugin runs and says what it found: the signature, who stands behind the plugin, the key, whether it may run on this computer and whether the licence covers it. `vss_cli plugin install <folder>` copies a plugin folder into your plugin folder (or, with `--for-everyone`, the folder of everyone on this computer) after the same checks, and `vss_cli plugin remove <id>` takes it out. `vss_cli plugin list` now shows the same findings for each plugin. A plugin arrives as a zip, which is unzipped with the system's own tool and installed from the folder. This build still runs no plugin.
