**Check, install and remove a plugin from the command line.** `vss_cli plugin verify <folder>` makes the checks that come before a plugin runs and says what it found: the signature, who stands behind the plugin, the key, whether it may run here and whether the licence covers it. `vss_cli plugin install <folder>` copies a plugin folder into your plugin folder (or, with `--for-everyone`, the folder of everyone on this computer) after the same checks, and `vss_cli plugin remove <id>` takes it out. A plugin signed with a key nobody has approved, like an unsigned one, installs only with `--allow-unsigned`. Neither command runs anything from a plugin.
