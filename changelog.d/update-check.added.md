**Studio can check for updates.** Studio asks once, at the first start, whether to check for a newer version automatically; the check is off until you turn it on. When it is on, Studio asks virtual-serial-studio.com once a day, and **Help > Check for updates...** asks at any time. A check is one request for a signed file and sends nothing about you. When a newer version is published, a banner and a status bar chip say so, and the update dialog shows what is new and can download, check and install the package. The settings are in **Settings** and on the **Updates** tab of **About**, and an administrator can turn the check off with `"update_check": false` in the policy file. A build without the feed keys says "This build cannot check for updates".
