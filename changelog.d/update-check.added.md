**Studio can check for updates.** Studio asks once, at the first start, whether to check for a newer version automatically; the check is off until you turn it on. When it is on, Studio asks virtual-serial-studio.com once a day, and **Help > Check for updates...** asks at any time. A check is one request for a signed file and sends nothing about you or your computer. When a newer version is published, a banner and a chip in the status bar say so, and the update dialog shows what is new and can download the package, check it against the signed file and start the install: the Windows installer, the macOS disk image, the Linux package through the system's package tool, or the archive in your Downloads folder. The settings are in **Settings** and on the new **Updates** tab of **About**, and an administrator can turn the check off with `"update_check": false` in the policy file. Until the feed keys are added to a build, it says "This build cannot check for updates" and makes no request. `vss_gui --check-tls` says whether a copy can make a secure connection.
