**`vss_license` refuses a request that does not say what it seems to, and `verify` counts the built-in revocation list.** `issue` and `revocations` refuse a request with a field the tool does not know and name the field in the message, so a misspelt `machines` no longer gives a licence with no computer binding. `issue` also refuses a request with no `features`, a non-empty `critical` (the tool writes none), a `licence_id` or `replaces` that is not of the form `VSS-<year>-<six digits>`, an `issued_at` more than 48 hours ahead of the computer's clock or after `expires_at`, and a trial whose `grace_days` is not 0, whose `seats` is not 1 or that names computers. `revocations` refuses a `sequence` below 1. `verify` always uses the revocation list built into the build, as Studio does, takes a `--revocations` file instead only when its sequence number is higher, and prints which list it used.
