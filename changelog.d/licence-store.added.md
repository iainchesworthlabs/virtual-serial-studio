**Studio looks for licence files on this computer.** It reads `.vsslic` files from a `licences` folder in its per-user data folder and from a per-machine folder an administrator can fill, checks each one offline and uses the one that gives the most. Nothing is fetched or sent. No screen shows the result yet, and this version trusts no key, so every build is still the Community edition. The About window's Licences tab now lists Monocypher, which checks the signatures.
