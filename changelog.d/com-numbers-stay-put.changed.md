**A new port takes a COM number the computer has had before, so numbers stay put.** Studio used to give each new port the next COM number above every number Windows knew, so the numbers climbed with every port you made and deleted. A new port now takes the lowest COM number Windows has kept that nothing is using, so deleting COM17 and making a port again gives COM17, and a setup keeps its numbers. Windows takes about 30 seconds to install a device for a COM number it has never had, and a fraction of a second for one it has had. Right after you delete a port Windows still counts its number as taken for about 45 seconds, and Studio waits for it rather than take another number; the window shows that it is working meanwhile.
