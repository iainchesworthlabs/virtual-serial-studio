**Uninstalling Studio on Windows no longer leaves the driver behind when the helper service will not go.** If the helper service could not be removed, the uninstaller stopped there, then deleted the removal script with the port devices and the driver package still on the machine and nothing left to remove them. It now carries on: the port devices are removed and the driver package is deleted as usual, and the uninstaller then tells you that the helper service stays, and keeps `driver-remove.log` so you can see why.
