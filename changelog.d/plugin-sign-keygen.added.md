**The plugin signing script can make a key and work with a key that has a passphrase.** `tools/plugin_sign.py keygen` makes a new Ed25519 key file that only its owner can read, refuses a file that already exists, and prints the public key. Every command that takes a key file can open one encrypted with a passphrase, given from a file, an environment variable or a prompt, never as an argument. This does not change Studio.
