**The plugin signing script can make a key and work with a key that has a passphrase.** `tools/plugin_sign.py keygen` makes a new Ed25519 key file that only its owner can read, refuses a file that already exists, and prints the public key. Every command that takes a key file can open one that is encrypted with a passphrase, given from a file, from an environment variable or at a prompt. The passphrase is never a command line argument. This is for people who sign plugins and does not change Studio.
