**A port made on a com0com pair no longer stops every save.** File > Save, the Topology JSON view, the setup kept for the next start and the diagnostic bundle all failed for as long as such a port existed. A port on a com0com pair is saved as an automatic port: the file does not say which pair it was on, so the next time the setup is opened Studio makes an automatic port again, which may be on another pair, or a Studio driver port if the driver has been installed since.
