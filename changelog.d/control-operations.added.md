**Making ports and sending bytes through the control endpoint.** A program, or `vss_cli`, can make and remove ports, link two ports and send bytes to a port. `vss_cli control port create <name>` and `vss_cli control link <id> <id>` print the new id, `vss_cli control port remove <id>` removes a port, and `vss_cli control send <id> --hex=<digits>` sends up to 64 KiB. Making, removing and linking ports needs the scope `control.ports`, and sending needs `control.data`. The local user's default role, `monitor`, has neither, so start the gateway with `--local-role=control` or use a token with those scopes. Every request is audit logged; a send records only its size.
