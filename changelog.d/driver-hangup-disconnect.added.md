**Hang-up and Disconnect on a Windows driver port.** The last two fault tiles in Advanced (**Open line matrix and faults**) now work for a Studio driver port too. Hang-up drops DCD and DSR at the program that has the port open, as a modem that hangs up does; the two lines stay low until the port linked to this one moves them again, and a port that is linked to nothing has them low already, so its program sees no change. Disconnect takes the port back from the program, so its handle stops working as that of an unplugged adapter does, and the same program or another can open the port again at once. The port keeps running in both cases, and like the line errors the tiles are off with the reason when no program has the port open.
