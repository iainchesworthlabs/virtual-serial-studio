**The GPU-drawn canvas no longer makes the window slower.** With Hardware (GPU) rendering the window now repaints without waiting for the display and redraws a node or link only when its own drawing changed. On the test machine a frame of the canvas went from 10 ms to 0.2 ms and a window resize step from 40 ms to about 17 ms. `VSS_RENDER_VSYNC=1` brings back the wait for the display.
