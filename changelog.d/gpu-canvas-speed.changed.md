**The GPU-drawn canvas no longer makes the window slower.** With Hardware (GPU) rendering the window now repaints without waiting for the display, uses the copying Direct3D swap chain on Windows, redraws a node or link only when its own drawing changed, and no longer uploads the canvas's part of the window for every frame. On the test machine a frame of the canvas went from 10 ms to 0.2 ms and a window resize step from 40 ms to 12 ms, level with Software (CPU). `VSS_RENDER_VSYNC=1` brings back the wait for the display and `QT_D3D_NO_FLIP=0` Qt's default swap chain. The GPU's time in a performance trace is now recorded only with `VSS_PROFILE_GPU=1`, because reading it slowed the canvas. The Monitor's bar is no longer laid out and repainted for every batch of traffic.
