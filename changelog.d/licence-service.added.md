**`vss_cli licence` shows the licence Studio uses on this computer.** It prints the edition, the state and the reason when the licence is not in force, then the licence number, who it is licensed to, its term, the days left, the seats and the licence files it found in both folders, one fact on each line. `vss_cli licence import <file>` checks a licence file as Studio does and copies it to your licence folder. The per-user licence folder is now one named path on each system: `%LOCALAPPDATA%\Virtual Serial Studio\licences` on Windows, `$XDG_DATA_HOME/virtual-serial-studio/licences` (or `~/.local/share/virtual-serial-studio/licences`) on Linux and `~/Library/Application Support/Virtual Serial Studio/licences` on macOS.
