**The plugin host can write and read a traffic recording.** A recording is a folder with an index, `recording.json`, and a file of JSON Lines for each recorded place: the bytes in and out, each line change, each fault and each loss, with the time of each in nanoseconds. The writer keeps a size limit and a time limit, can keep only the last few minutes, hashes each file as it writes it and writes the index last, so a folder without an index is not taken for a whole recording. The reader checks the index, each line, the byte counts and the SHA-256 of each file, and refuses a link, a file the index does not list and a format newer than it reads. The format is written in `docs/plugins.md`, section 19.6. Capture and replay use it.
