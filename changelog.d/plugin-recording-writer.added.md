**The plugin host can write and read a traffic recording.** A recording is a folder with an index, `recording.json`, and a file of JSON Lines for each recorded place: the bytes in and out, each line change, fault and loss, with times in nanoseconds. The writer keeps a size limit and a time limit, and writes the index last, so a folder without an index is not taken for a whole recording. The reader checks the index, each line, the byte counts and the SHA-256 of each file. The format is in `docs/plugins.md`, section 19.6. Nothing in Studio uses it yet.
