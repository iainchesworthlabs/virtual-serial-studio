**A listening address can say who may connect.** Add `?allow=` and addresses or ranges such as `192.168.1.0/24` to a `tcp-listen://`, `udp-listen://` or `rfc2217-listen://` address. A TCP or RFC 2217 client outside the list is closed as soon as it connects and a UDP datagram from outside it is ignored. The network dialog and `vss_cli bridge` warn when an RFC 2217 server, which has no password, can be reached from another computer and has no list. Studio never changes the operating system's security settings on its own: the firewall and permission fixes it offers are shown as the exact command, and run only when you press the button.
