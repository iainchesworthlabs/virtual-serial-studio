**New library calls `hub::add_source` and `hub::remove_source`, and `hub::add_member` and `hub::remove_member`,** add one source to a one-way link (a join, a redirect or a monitor) or take one off, and put one endpoint on a bus or take one off, without touching the other routes: the link keeps its id, options, owner and counters. They refuse a link of the wrong kind (`unsupported`), an unknown link or endpoint (`not_found`), an endpoint that is there already or, for a bus, on another bus (`already_exists`), a loop (`cycle_detected`), and taking off the last source or going below two bus members (`invalid_argument`; remove the link instead). A one-way link with several sources is saved as a join, as before, and with one again as a redirect or a monitor, so the file format is unchanged. Taking off the source that owns a link releases the owner, and a new source's bytes are held back by the owner policy like the others'.
