**Set up Virtual Serial Studio says when only the helper failed, and carries on when the driver is already up to date.** When the helper service could not be installed or started, Studio said "Setup did not finish"; it now says the driver is installed and only the helper is left. When Windows answers that no device was updated because the devices already use this driver or a newer one, set-up goes on to the helper if the driver store holds this version of the package, where before it stopped and left an old helper in place.
