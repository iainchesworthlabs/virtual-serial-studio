**Studio no longer offers or picks a COM number that Windows keeps for a port that is not there.** Windows holds the number of a port that was unplugged or removed in its COM name database, which no list of ports shows, and the driver refused such a number after it had made and removed the port, so a form that offered it failed with "already exists". Studio now reads which numbers Windows keeps, offers and chooses only free ones, and, if Windows still refuses a number, says which COM number clashed and moves to a free one. Where it cannot read them it lets Studio pick the number and says so.
