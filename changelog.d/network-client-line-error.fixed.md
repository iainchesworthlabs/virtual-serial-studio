**A network client no longer drops its connection on a framing error.** A device behind a network serial server (RFC 2217) reports a framing, parity, overrun or break error when it receives a byte badly, which is common on a noisy RS485 bus. Studio treated that as the end of the connection and kept reopening it. The error is now counted and written to the log (at most once a second), and the connection stays open.
