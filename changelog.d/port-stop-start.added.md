**A network port, or a serial device, can be stopped and started without removing it.** Choose **Stop** in the port's menu on the canvas, or the **Stop** button in the Inspector, to close it: a network client lets go of the other computer, a server lets go of its address and drops its clients, and a serial device is closed so another program can use it. The port keeps its name and its links, and nothing tries to connect it again while it is stopped. **Start** opens it again; a client whose other computer refuses keeps trying. A stopped port shows a grey tile with a pause icon and a **Stopped** chip, and its state reads **Stopped** in the ports list and the Inspector. This is different from Failed. The stopped state is not saved in the setup file: a saved setup starts every port.
