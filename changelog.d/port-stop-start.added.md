**A network port, or a serial device, can be stopped and started without removing it.** Choose **Stop** in the port's menu on the canvas or in the Inspector, to close it: a network client lets go of the other computer, a server lets go of its address and drops its clients, and a serial device is closed so another program can use it. The port keeps its name and its links. **Start** opens it again. A stopped port shows a grey tile and a **Stopped** chip, and reads **Stopped** in the ports list and the Inspector. The stopped state is not saved in the setup file: a saved setup starts every port.
