**The Windows installer no longer leaves the driver, the helper service or the PATH entry behind when an upgrade is cancelled or an uninstall is run by a script.** If you cancelled an upgrade, or ran `Uninstall.exe /S _?=<folder>`, Studio was removed but these stayed. They are now kept only during a real upgrade. An uninstall run any other way removes them (`Uninstall.exe /S _?=<folder>` still leaves `Uninstall.exe` and the folder). From this version on, an upgrade that is cancelled or fails also removes them,; cancelling an upgrade from an older version leaves them as before. Also fixed: adding Studio to a PATH that held exactly one entry was joined onto it, a PATH value of an unexpected type was rewritten, removing Studio from a PATH over the length limit was refused, and a failed PATH removal deleted the log (`path-setup.log`) the message told you to read.
