**The Windows installer no longer leaves the driver, the helper service or the PATH entry behind when an upgrade is cancelled or an uninstall is run by a script.** The installer used to treat any uninstall that ran from the install folder as part of an upgrade. If you cancelled an upgrade, or ran `Uninstall.exe /S _?=<folder>` (the form that waits for the uninstall to finish), Studio and its uninstaller were removed but the helper service, the driver package and the PATH entry stayed, with nothing left to remove them. The new installer now tells the old uninstaller that it is an upgrade, and only that keeps these things. An uninstall run any other way removes them, and an upgrade that is cancelled or fails removes them too. Also fixed: adding Studio to the system PATH joined it onto the end of the only entry when the PATH held exactly one, and a failed PATH removal deleted the log (`path-setup.log`) that the message told you to read. The log now stays in the install folder when the PATH could not be changed.
