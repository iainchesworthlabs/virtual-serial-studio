**The Linux release has a `.deb` and an `.rpm`.** `virtual-serial-studio` installs `vss_gui` and `vss_cli` for Debian and Ubuntu (`apt install ./virtual-serial-studio_*.deb`) and for Fedora and Red Hat (`dnf install ./virtual-serial-studio-*.rpm`), with a launcher entry, an icon, the licence texts and the system libraries it needs as dependencies. The programs are in `/opt/virtual-serial-studio`.
