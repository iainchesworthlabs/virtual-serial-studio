**The Linux release has a `.deb` and an `.rpm`.** `virtual-serial-studio` installs `vss_gui` and `vss_cli` for Debian and Ubuntu (`apt install ./virtual-serial-studio_*.deb`) and for Fedora and Red Hat (`dnf install ./virtual-serial-studio-*.rpm`), with a launcher entry, an icon, the licence texts and the system libraries it needs as dependencies. The programs are in `/opt/virtual-serial-studio` with the Qt libraries they were tested with, and `/usr/bin` links to them. The release workflow builds both with CPack (`VSS_PACKAGE=ON`), installs each in a clean Ubuntu 26.04 and Fedora 44 container, starts the programs there, and removes them again, before the `.tar.gz` and the two packages are published together.
