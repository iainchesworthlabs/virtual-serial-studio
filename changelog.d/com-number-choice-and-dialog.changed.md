**Choose a COM number when you add a Port on the canvas, and see which numbers are free when you change one.** On Windows the Add sheet for a Port has a **COM number** field, set to Automatic, with the free numbers in its list. **Change COM number** now has a list of free numbers you can also type into, and a list of the numbers in use that names what holds each one. A number in use is refused beside the field before you press **Change number**.
