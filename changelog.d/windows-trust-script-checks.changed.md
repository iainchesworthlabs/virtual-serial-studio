**`install-trust.ps1` checks everything before it adds a certificate, and trusts the root for code signing only.** A package that was changed after it was signed adds nothing, and if a step after the first certificate fails, the certificates that run added are taken out again. The root is no longer trusted for web sites or mail. `-Uninstall` removes only certificates that the script added (they carry the friendly name "Virtual Serial Studio (install-trust.ps1)"); `-IncludeUnmarked` also removes ones that an earlier version added.
