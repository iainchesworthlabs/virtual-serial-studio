**The helper service is registered with its path in quotes.** The path of `vsscom_helper.exe` has a space in it (`Program Files`), and Windows PowerShell 5.1 passed it to `sc.exe` without quotes, so Windows tried `C:\Program.exe` first, as SYSTEM, and would have run a program placed there. Set-up now registers the service with `New-Service`. Choose **Set up Virtual Serial Studio** again to replace a service that was installed the old way.
