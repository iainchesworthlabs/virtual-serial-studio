**The helper service is registered with its path in quotes.** The path of `vsscom_helper.exe` has spaces in it (`Program Files`), and Windows PowerShell 5.1 passed it to `sc.exe` without quotes, so each time the service started Windows tried `C:\Program.exe` and the other shorter names first, as SYSTEM, and would have run a program placed there. Set-up now registers the service with `New-Service`, reads the stored path back from the registry, and takes the service out again if the path has no quotes. Choose **Set up Virtual Serial Studio** again to replace a service that was installed the old way.
