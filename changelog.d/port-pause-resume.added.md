**A network port, or a serial device, can be paused and resumed, and the setup remembers the pause.** Choose **Pause** in the port's menu on the canvas, or the **Pause** button in the Inspector, to close it for a while: a network client lets go of the other computer and does not try again, a server lets go of its address and drops its clients, and a serial device is closed. The port keeps its name and its links, and what is sent to it while it is paused is lost, not held. **Resume** opens it again. A paused port shows an accent tile with a pause icon and a **Paused** chip, and reads **Paused** in the ports list and the Inspector, next to **Stopped** when the list is sorted by state. Unlike a stopped port, a paused port is saved in the setup file as `"paused": true`, so the setup opens with it still paused; a file without the field runs the port as before.
