**`vss_gate`, a first slice of the control endpoint.** `vss_gate` serves a versioned control API to the programs of the user who starts it, over a named pipe (Windows) or a Unix domain socket (Linux, macOS) that only that user can open; nothing listens on the network. It is a client of `vss_agent` and asks the operating system who made each connection before it reads a byte of it. This slice can report its status and list the agent's ports and links; programs may monitor by default, and every connection and refusal is written to an audit log in a directory only the user can read. `vss_cli control status` shows who you are to the gateway and what you may do, and `vss_cli control stop` ends it without closing a port. `vss_gate` is not in the installers and is started by hand; `docs/remote-control.md` has the design and what comes next. Building now needs Boost 1.88 or later.
