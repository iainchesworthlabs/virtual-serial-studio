**Changing the settings of a real serial device now works.** Apply and restart in Settings for a port that is a real device (for example COM5) failed with "Access is denied", because Studio tried to open the device again while it still had it open. Studio now lets go of the device first, then opens it with the new settings, and puts the old settings back if the device refuses them. If another program really has the port open, the sheet now says so and tells you to close that program and try again.
