**The plugin folders and the policy file are under `Virtual Serial Studio` on Windows and macOS.** The folder now has the same name as the install folder: `%ProgramData%\Virtual Serial Studio\plugins` for plugins installed for everyone, `%LOCALAPPDATA%\Virtual Serial Studio\plugins` for your own, and `%ProgramData%\Virtual Serial Studio\policy.json` for the administrator's policy. On macOS they are under `/Library/Application Support` and `~/Library/Application Support`. Move any plugin or policy file you put in a `VirtualSerialStudio` folder. Linux is unchanged.
