**The messages of the plugin API's extension points are defined in code.** `libs/vss_plugin` has a typed struct for each message of instances and parameters, generators, fixtures and rule sets, behaviour modifiers, automation adapters, recordings, bundle sections, timelines, and the decode stream with its decoded frames and triggers. Each struct is read from and written to a frame with the same strict checks as the common messages: every field has a type and a limit, bytes travel only in the blob, and a message that is not as its role says is refused. `docs/plugin-api-reference.md` lists every message with its direction, fields and limits for people who write plugins. Nothing in Studio starts a plugin or sends these messages yet.
