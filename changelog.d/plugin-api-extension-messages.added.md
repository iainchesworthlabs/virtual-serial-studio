**The messages of the plugin API's extension points are defined in code.** `libs/vss_plugin` has a typed struct for each message of instances and parameters, generators, fixtures and rule sets, behaviour modifiers, automation adapters, recordings, bundle sections, timelines, and the decode stream. `docs/plugin-api-reference.md` lists every message with its fields and limits for people who write plugins. The plugin host sends and answers those of generators, decoders, capture, replay and bundle sections. The others are not served yet.
