**The plugin host creates the instances wanted of a plugin and keeps the running plugin in step with them.** When a plugin is ready the host makes each instance wanted of it, tells the plugin when parameters change, stops one no longer wanted, and makes them all again on a restart. An instance the manifest does not allow, or the plugin refuses, is shown as refused with the reason. `vss_cli plugin run --instance <kind>:<type>[=<params>]` makes an instance from the command line and prints each change of its state.
