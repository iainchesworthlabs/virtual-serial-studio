**A setup file with a mistake is refused when you open it, and every setup file needs `"version": 1`.** A file without the line `"version": 1`, or with another version, no longer opens, so a file written by hand needs the line added. A member of the wrong type (such as `"kind": ["tcp"]`) and a member Studio does not know (such as `"port"` for `"ports"`) are refused too. Before, the mistake was read as a default and saving wrote the loss back. The window and `vss_cli` do not yet say which member is wrong.
