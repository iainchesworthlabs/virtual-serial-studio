**A setup file with a mistake is refused when you open it, and every setup file needs `"version": 1`.** A file without the line `"version": 1`, or with another version, no longer opens, so a file written by hand before this needs the line added. A member of the wrong type (such as `"kind": ["tcp"]` or `"capture": "false"`) and a member Studio does not know (such as `"port"` for `"ports"`, or `"delay"` for `"delay_ms"`) are refused too. Before, the mistake was read as a default, and saving then wrote the loss back over the file. The window and `vss_cli` say that the file could not be opened; they do not yet say which member is wrong.
