**The plugin host can now serve a decoder plugin and the sections a plugin adds to a support bundle.** For a decoder it sends the traffic of the places the user chose, in order, with no more than 256 KiB sent and not yet acknowledged, and it says where bytes were dropped because the plugin was too slow. It keeps the frames and triggers the decoder finds in the decode store, within the store's limits. For a bundle section it asks the plugin for its files, reads each one from one open handle and checks its size and hash. Studio uses the decoder. The support bundle dialog does not ask a plugin for its sections yet.
