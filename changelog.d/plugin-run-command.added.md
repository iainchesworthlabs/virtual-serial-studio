**`vss_cli plugin run` runs one installed plugin.** `vss_cli plugin run <id>` runs a plugin under the plugin host and prints each change of its state (starting, running, waiting to start again, stopped after failing, off, needs your decision, blocked by the administrator, needs a licence or cannot be used), its process id, how far it is confined, its status and each line of its output and log, as plain text or, with `--json`, as one JSON object on each line. It makes no decision about trust, so a plugin that needs one is not run and the command says to decide in Studio. It runs until `Ctrl-C`, or for `--seconds <n>` once the plugin is running, and always stops the plugin in order. `--root`, `--trust` and `--data` name the plugin folders, the file of your decisions and the folder where plugins keep their data.
