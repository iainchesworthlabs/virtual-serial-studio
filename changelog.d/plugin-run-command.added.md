**`vss_cli plugin run` runs one installed plugin.** `vss_cli plugin run <id>` runs a plugin under the plugin host and prints each change of its state, its process id, its status and each line of its output and log, as plain text or, with `--json`, as one JSON object on each line. A plugin that needs a trust decision is not run; the command says to decide in Studio. It runs until `Ctrl-C`, or for `--seconds <n>` once the plugin is running. `--root`, `--trust` and `--data` name the plugin folders, the file of your decisions and the folder for plugin data.
