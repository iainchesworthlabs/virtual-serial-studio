**The canvas repaints faster while you resize the window.** The dot grid behind the topology cost about 50 ms for every repaint of a large canvas, which made dragging a window corner stutter. Studio also writes a line to `stalls.log` in its local data folder when the window stops answering for two seconds (this stays on your computer). The performance trace is now available in Release builds too and remembered between starts (Settings, Performance, Profiling).
