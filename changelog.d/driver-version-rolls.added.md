**Studio tells you when the Windows driver is out of date, and updates it.** Studio now reads three versions: the driver package in Windows' driver store, the one that came with this copy of Studio, and the version the running ports speak. The Setup check, the About page and the set-up dialog show them in words. When the installed driver is older than the one in Studio, the Setup check and the start page say so and offer Update the driver, with a note that ports that are open are closed while it is replaced. Nothing is shown when the driver is up to date. The driver package version now comes from one file, `drivers/windows/driver-version.json`, and the pull request gate fails when the driver changed without a new version. Set up also stops with an error, instead of looking fine, when Windows keeps an older driver than the one it was asked to install.
