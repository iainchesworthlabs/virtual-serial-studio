**A library that checks licence files.** `libs/vss_license` reads a signed licence file, checks its Ed25519 signature against the public keys built into the program and works out what the licence allows, all without a network connection. Nothing in Studio uses it yet, and this version trusts no key, so it accepts no licence. The signature code is Monocypher 4.0.2, kept unchanged in `third_party/monocypher`.
