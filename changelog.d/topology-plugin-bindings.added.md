**A setup file can say which plugins it needs.** A port or a link may have an optional list named `plugins`. Each entry gives a plugin's `id`, the `kind` of thing it provides (`fixture`, `generator`, `modifier` or `decoder`), its `type`, and optionally a `name`, `publisher`, `key_id`, `version`, where to get it (`get_it_from`), `on_timeout` and its settings (`params`). Studio checks the list when it reads a setup and never needs the plugin to do so. The file's `version` is still 1 and a setup without plugins is written exactly as before. This build does not run plugins, and a setup that is opened and saved again from the window does not keep the list yet.
