**A setup file can say which plugins it needs.** A port or a link may have an optional list named `plugins`. Each entry gives a plugin's `id`, the `kind` of thing it provides (`fixture`, `generator`, `modifier` or `decoder`), its `type`, and optionally a `name`, `publisher`, `key_id`, `version`, `get_it_from`, `on_timeout` and its settings (`params`). Studio checks the list when it reads a setup. The file's `version` is still 1. This build does not run plugins.
