**Open in monitor now shows the port, and decoding and the monitor port can be found in the Advanced view.** **Open in monitor** (on a port, and on a monitor link) now sets the Monitor's port filter to that port and says so in the status bar, where before it only brought the Monitor forward. Selecting a port that is the end of a monitor link now says in the Inspector that it is a monitor and which port it copies, with a button to open that port in the Monitor. A monitor link's menu says why it has no settings and offers **Open in monitor**. With a plugin that has a decoder switched on, a port's menu (and a monitor link's) offers **Decode as...**, which asks which decoder to use and starts it on that port; what it finds is shown in Plugins. The plugin tiles in the palette for a fixture type such as **Recorded device** are now disabled, with the reason in the tooltip, until the engine can play a recording as a device; before, they looked usable and did nothing.

**A monitor takes the settings of the port it watches.** In the Add monitor sheet, choosing an existing port as the watched end now shows that port's baud rate and framing, labelled as taken from the port, and uses them; they can be edited only while no existing port is chosen. Settings for the copy end of a monitor link shows the same values and does not allow changing them. A port with no traffic yet now says so in the Monitor, with the port's state, and Inspect always shows that port's Inspector. The Settings of a network client whose address was not in the setup now shows the network settings instead of the serial ones.

**Double-click opens Settings on the canvas.** In Advanced, double-clicking a port, network port, bus member, monitor or plugin item opens its Settings, as Settings in its menu does, and double-clicking a link opens the link's settings. A monitor link has no settings, so double-clicking it opens the port it watches in the Monitor. Double-clicking empty canvas does nothing. Where the canvas is not being edited, double-click still opens the Inspector.
