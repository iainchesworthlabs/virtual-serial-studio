**Studio can run plugins.** The plugin host starts each installed plugin that may run, keeps it running and stops it. A plugin runs when its files and signature check out, a licence covers it where it needs one, and it is trusted: an official plugin by its signature, any other by your decision for that exact copy. It gets only the permissions that were granted, and its sandbox is built from those. A plugin that fails is started again after 1, 2, 4 and 8 seconds and is stopped after the fifth failure in ten minutes. On Windows a plugin is confined in an AppContainer; on Linux and macOS official plugins run without confinement and say so, and other plugins run there only when you allow that for one plugin. The Plugins page shows what it does, and `vss_cli plugin run` uses it from a command line.
