**The window no longer freezes while Windows installs new ports.** Choosing **Create** or **Apply** in Simple view, **Create port**, **Create pair** and **Attach device** in Advanced view, opening a setup file or a template, starting the ports from last time, and **Apply changes** in the JSON editor held the whole window for 15 to 20 seconds. The ports are now made in the background. The button changes to **Creating**, **Attaching** or **Applying**, a progress bar shows, and the rest of the form is disabled. If it fails, the form comes back with the same message as before and nothing is changed.
