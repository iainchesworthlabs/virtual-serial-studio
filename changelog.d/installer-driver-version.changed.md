**The Windows installer and Set up now look at the version of the installed driver.** It offers to update an older one (the box is ticked), leaves one of the same version as it is (with an unticked box to install it again) and leaves a newer one alone. A silent install updates the driver only when the installer's is newer, and `/REPAIRDRIVER=1` installs it again. Studio's Set up no longer puts an older driver over a newer one.
