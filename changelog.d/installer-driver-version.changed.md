**The Windows installer and Set up now look at the version of the driver that is installed.** The installer's driver page says which driver is already installed. It offers to update an older one (the box is ticked), leaves a driver of the same version as it is (with an unticked box to install it again) and leaves a newer one alone. A silent install updates the driver only when the installer's is newer, and `/REPAIRDRIVER=1` installs it again. Studio's Set up Virtual Serial Studio no longer puts an older driver over a newer one. The uninstaller says that it removes every driver package, the older versions that updates left behind included.
