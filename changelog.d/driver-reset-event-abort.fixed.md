**Windows COM port drivers: three fixes.** The error, break and event characters a program set are cleared when it closes the port, so the next program no longer inherits them. An event raised after a program cancelled its `WaitCommEvent` is kept for the next wait instead of being lost. With abort on error, a write that a line error ends no longer leaves its bytes behind for the other end to read, and it reports only the bytes that were sent.
