**Raise line errors at a program from a Windows driver port.** On Windows, the fault tiles in Advanced (**Open line matrix and faults**) now work for a Studio driver port as well as a fixture: Parity error, Framing error, Overrun and Break are raised at the program that has the port open, as bad character times on a wire would be. The program sees them through the calls it uses on hardware: `ClearCommError` reports the error, `WaitCommEvent` reports `EV_ERR` or `EV_BREAK` when its mask asks for them, the error character arrives in the data for a parity or framing error when it set one, and its reads and writes end until it clears the error when it chose abort on error. The port keeps running, and Studio shows no error event. The tiles are off with the reason when no program has the port open, because the driver drops an error that has nobody to receive it, and Hang-up and Disconnect are not offered on a driver port. The driver and Studio share interface version 4, so update them together.
