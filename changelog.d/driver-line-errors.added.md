**Raise line errors at a program from a Windows driver port.** On Windows, the fault tiles in Advanced (**Open line matrix and faults**) now work for a Studio driver port as well as a fixture: Parity error, Framing error, Overrun and Break are raised at the program that has the port open. The program sees them through the calls it uses on hardware: `ClearCommError` reports the error, and `WaitCommEvent` reports `EV_ERR` or `EV_BREAK` when its mask asks for them. The tiles are off when no program has the port open. The driver and Studio share interface version 4, so update them together.
