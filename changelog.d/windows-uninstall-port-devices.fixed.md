**Uninstalling removes the port devices as well.** Every COM port Studio made left a hidden device behind, which kept its COM number in use after the driver was gone. `remove-driver.ps1` now removes those devices (`SWD\VSSCOMUM\*`, the absent ones too) after the helper service stops and before it deletes the driver package, and ends with code 7 if one is left. This needs Windows 10 version 2004 or later.
