**Uninstalling Studio removes the port devices as well.** Every COM port Studio made left a hidden device behind, which kept its COM number in use after the driver was gone. `remove-driver.ps1` now removes those devices, the absent ones too, after the helper service stops and before it deletes the driver package. A device that cannot be removed does not stop the uninstall: the package is deleted first and the device is named at the end, with exit code 7.
