**On Windows, a link's delay and a scripted reply's delay are now late by about a millisecond or less.** Windows fired every timer on a 15.6 ms tick, so a delay of 1 ms took about 15 ms and a delay of 20 ms about 30. While a setup runs, Studio now asks Windows for a 1 ms timer period. A delay is still never shorter than the number you set. Windows 11 may stop honouring the request while every Studio window is minimised or covered. Linux and macOS were not affected.
