**A link can carry its traffic at the speed of a serial wire.** Turn on **Wire timing** in a link's **Settings...**, or add `"wire_timing": { "bit_rate": 115200, "framing": "8N1" }` to the link in a topology file. A write then takes as long as it would on a wire, counted from the sending port's baud rate and framing, the next write waits for it to finish, and a break holds back the bytes after it for the length of the break. It is off unless you turn it on, and a Studio from before it will not open a file that has it. A half-duplex bus now counts the sender's real framing too. For a gap under a millisecond Studio waits on the processor, using at most a tenth of one core.
