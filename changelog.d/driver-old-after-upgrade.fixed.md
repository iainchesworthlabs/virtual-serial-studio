**A new port can be made again after an upgrade over an older Studio.** The Windows driver was changed to version 5 without a new package version, so Windows kept the older driver when Studio was set up again, and Studio refused every port that driver made ("unsupported by this transport"). The driver package now has a new version, so Set up Virtual Serial Studio replaces the old driver. A PC that still has the old driver now says so in words ("The Virtual Serial Studio driver is out of date") and offers Set up, in place of the bare "unsupported by this transport".
