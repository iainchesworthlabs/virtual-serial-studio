**A plugin you added for yourself can be upgraded from Plugins.** **Add a plugin...** used to refuse a plugin that was already installed for you, with "Remove it first to add a different copy". Now, when the folder you choose is another version of a plugin you have, the question reads **Upgrade** *name* (or **Replace**, for the same version with other files or an older version) and lists the version you have next to the new one. When you choose **Upgrade plugin**, Studio switches the plugin off if it is running, waits until it has stopped and replaces the plugin's folder. The plugin's settings, instances and saved data stay. The new files are a version you have not decided about, so the plugin stays in Needs your decision until you decide. A folder with exactly the files you have is still refused. The command the question shows for installing for everyone ends with `--replace` when a copy for everyone is installed already.
