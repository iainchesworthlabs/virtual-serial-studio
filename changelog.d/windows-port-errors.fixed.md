**A port that cannot be made no longer says "permission denied" and nothing else.** A missing driver, a helper service that is not installed, stopped or older than Studio, and a helper that refuses your account each have their own message with the next step, and the engine's code and the call that failed are behind Copy details. A refusal that Studio cannot trace to the setup says so and points to the Setup check instead of telling you to run Studio as administrator. The Advanced canvas Add sheet says the same, with a Set up Virtual Serial Studio button under the reason.
