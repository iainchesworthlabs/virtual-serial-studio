**Add port and Change COM number offer a COM number that a removed Studio port used.** A number such as COM1 to COM8 that a Studio port once had and that is gone from Device Manager was listed as "Reserved by Windows" and could not be chosen. A number is now refused only when something holds it: a plugged-in device, a name that already works, or an unplugged device of another kind that keeps the number for when it comes back, which is named. COM1 and COM2 are offered like any other free number.
