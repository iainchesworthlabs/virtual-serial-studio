**Add port and Change COM number offer a COM number that a removed Studio port used.** COM1 to COM8, or any number, that a Studio port once had and that is gone from Device Manager was listed as "Reserved by Windows" and could not be chosen, because Windows keeps the number of a removed port. A number is now refused only when something holds it: a device that is plugged in, a name that already works, or an unplugged device of another kind that keeps the number for when it comes back, which is named ("Unplugged Windows device USB Serial Device (COM10)"). COM1 and COM2 are offered like any other free number. Automatic still starts at COM3 and still prefers a number this computer has had before, which is made in a fraction of a second.
