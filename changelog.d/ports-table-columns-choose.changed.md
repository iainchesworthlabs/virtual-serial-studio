**The Advanced Ports table keeps its place, and its columns can be chosen.** The table no longer jumps back to the first column when a port changes while you have scrolled sideways; the selection and filter stay too. Escape clears the filter box above the table. Drag a column heading to move it, and right-click a heading, or press `Ctrl+Alt+M` in the table, to choose which columns show. New columns are Kind, Address, Settings (for example 9600 8N1), Baud rate, Data bits, Parity, Stop bits, Flow control and Errors. The order, shown columns and widths are kept for the next start.
