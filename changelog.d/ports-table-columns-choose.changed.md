**The Advanced Ports table keeps its place, and its columns can be chosen.** Scrolling the table sideways to see a column such as Dropped no longer jumps back to the first column each time a port's state or traffic count changes; the scroll position, selection and filter stay as they are. The filter box above the table is now the same height as the other inputs, with its clear button inside it, and Escape clears it. Drag a column heading to move it, and right-click a heading, or press `Ctrl+Alt+M` in the table, to choose which columns show. New columns are Kind, Address, Settings (for example 9600 8N1), Baud rate, Data bits, Parity, Stop bits, Flow control and Errors. A value Studio does not know for that kind of port shows a dash. `Ctrl+Alt+Shift+Left` and `Ctrl+Alt+Shift+Right` move the column the cursor is in. The order, the shown columns and their widths are kept for the next start.
