**`install-trust.ps1` checks the package first and trusts the root for code signing only.** The script reads the signature of the file it is given and checks the chain before it adds a certificate, so a signed file that was changed adds nothing, and if a later step fails the certificates that run added are taken out again. A root that this version adds is trusted for code signing only, not for web sites or mail; a root that is already in the store is left as it is, and the script says whether it is limited. `-Uninstall` removes only certificates the script added (they carry the friendly name "Virtual Serial Studio (install-trust.ps1)"), and `-IncludeUnmarked` also removes ones an earlier version added.
