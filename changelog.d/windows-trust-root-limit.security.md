**`install-trust.ps1` checks the package first and trusts the root for code signing only.** The script checks the signature and chain of the file it is given before it adds a certificate, so a signed file that was changed adds nothing, and if a later step fails the certificates it added are taken out again. A root that this version adds is trusted for code signing only, not for web sites or mail. `-Uninstall` removes only certificates the script added, and `-IncludeUnmarked` also removes ones an earlier version added.
