**`vss_license`, the owner's command line tool for issuing licence files.** It is not in any installer or package, and customers do not need it: a licence is imported with Help, Licence in Studio. `inspect` prints what a licence or revocation file says and whether its signature verifies, and `verify` runs the check Studio will run. `issue` and `revocations` sign a request and write a new file; they never overwrite one. `keygen` makes a key pair and writes the private half to a new file that only its owner can read.
