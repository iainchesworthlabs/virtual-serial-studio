**`vss_license`, a command line tool for licence files.** `inspect` prints what a licence or revocation file says and whether its signature verifies, and `verify` runs the check Studio will run, for any date and computer name. `issue` and `revocations` check a request, sign it, check their own output and write a new file; they never overwrite one. A request with a field the tool does not know is refused and the message names the field, so a misspelt `machines` cannot give a licence with no computer binding. `issue` also refuses a request with no `features`, a licence id that is not `VSS-<year>-<six digits>`, an `issued_at` more than 48 hours ahead of the computer's clock, and a trial that has a grace period, more than one seat or named computers. `verify` always counts the revocation list built into the build, as Studio does, and prints which lists it used. `keygen` makes a key pair, writes the private half to a new file that only its owner can read and prints the public half. The private key comes from a file or an environment variable, never from the command line, and is never printed. The tool works offline, is built with the other tools and is not installed with Studio.
