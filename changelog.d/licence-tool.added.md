**`vss_license`, the owner's command line tool for issuing licence files.** It is not in any installer or package, and customers do not need it: a licence is imported with Help, Licence in Studio. `inspect` prints what a licence or revocation file says and whether its signature verifies, and `verify` runs the check Studio will run, for any date and computer name. `issue` and `revocations` check a request, sign it, check their own output and write a new file; they never overwrite one. `keygen` makes a key pair, writes the private half to a new file that only its owner can read and prints the public half. The private key comes from a file or an environment variable, never from the command line, and is never printed. The tool works offline and is built from source with the other tools.
