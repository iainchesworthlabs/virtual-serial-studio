**Tools, Plugins... shows the plugins installed on this computer.** Each plugin has a row with its trust line (Official, Signed by someone, Unsigned, or signed by an author you have not approved), its version, its state and a switch. The detail shows what it adds, who made it, what its signature says, its fingerprint, how far this computer can keep it apart from your files, what it may do, where the setup uses it and its recent messages. **Review and decide** asks whether to run it, for that version only, and lists every permission it asks for in plain sentences; the permissions it marks as optional can be unticked. **Import a key...** approves an author's public key after you compare its fingerprint with the one the author published, and **Run without isolation...** is a separate question. Text a plugin supplies is always shown as plain text. This build cannot start a plugin yet: a plugin that you have decided on is shown as Off, with "Not available in this build", and Studio keeps your choice. Plugins also show up elsewhere in the window: the Advanced toolbox has a **Plugins** group with a tile for each fixture type of a plugin that is switched on (a tile that cannot be used now is disabled, with the reason, and a tile for a plugin you did not switch on is not there); a port that a plugin provides is marked **Plugin not available** on the canvas and in the Inspector, with what it does meanwhile and an action; notices at the top of the window say that a new plugin was found, that a plugin changed, stopped or was withdrawn; a chip in the status bar says **Reading data** or **Recording** while a plugin reads data; and the Licence page links to **Plugins**. **Add a plugin...** looks into the folder first and shows what it found before anything is copied.
