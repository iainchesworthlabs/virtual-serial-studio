**Tools, Plugins... shows the plugins installed on this computer.** Each plugin has a row with its trust line (Official, Signed by someone, Unsigned, or signed by an author you have not approved), its version, its state and a switch. The detail shows what it adds, who made it, what its signature says, its fingerprint, how far this computer can keep it apart from your files, what it may do, where the setup uses it and its recent messages. **Review and decide** asks whether to run it, for that version only, and lists every permission it asks for in plain sentences; the permissions it marks as optional can be unticked. **Import a key...** approves an author's public key after you compare its fingerprint with the one the author published, and **Run without isolation...** is a separate question. Text a plugin supplies is always shown as plain text. This build cannot start a plugin yet: a plugin that you have decided on is shown as Off, with "Not available in this build", and Studio keeps your choice.
