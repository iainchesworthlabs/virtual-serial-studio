**The control gateway can check its own audit log, and on Windows it reads the access list of a directory it is given.** `vss_cli control audit verify` checks that every line of the audit log is a record, that the numbers follow each other and that each line carries the hash of the line before. It prints `intact` and the number of records, or `broken` with the file, the line and what is wrong. A broken chain shows a line was changed or moved; an intact one does not prove nobody rewrote the whole log. On Windows, an existing directory for the audit log or token file is refused when its access list lets in anyone but this user, the system and the Administrators group.
