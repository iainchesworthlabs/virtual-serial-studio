**Virtual Serial Studio shows its icon where an installed program needs one.** The window, the taskbar and the dock use it; `vss_gui.exe` and `vss_cli.exe` carry it as their Windows file icon next to their version information; the macOS bundle names it in `CFBundleIconFile`; and a Linux install puts it in the hicolor theme with a `vss_gui.desktop` entry. Help, About shows the icon, the version, the licence and a link to the source code.
