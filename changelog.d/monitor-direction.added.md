**A monitor can copy only what a port sends, only what it receives, or both.** A monitor link has a new optional setting in the saved file, `"direction"`, with the values `"both"`, `"transmit"` (what the port's program writes) and `"receive"` (what links write into the port). A file without it, which is every file saved before, means `"both"`, which is what a monitor now does by default. Any other value is refused with a message that names the allowed ones, and a link that is not a monitor cannot have a direction other than `"both"`.
