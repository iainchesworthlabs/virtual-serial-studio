**Data now passes through a port that has more than one link, and a monitor shows both directions.** Before, bytes that a link wrote into a port were not sent on along that port's other links. A client linked two-way to a port, with that port linked two-way to a network server and also on a bus, delivered nothing to the server or the other bus members, and the server's answers did not reach the client. Studio now sends the bytes on, once to each port and never back to where they came from, and a monitor shows both directions.
