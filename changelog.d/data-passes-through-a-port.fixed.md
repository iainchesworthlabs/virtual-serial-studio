**Data now passes through a port that has more than one link, and a monitor shows both directions.** Before, bytes that a link wrote into a port were not sent on along that port's other links. A client linked two-way to a port, with that port linked two-way to a network server and also on a bus, delivered nothing to the server or the other bus members, and the server's answers did not reach the client. A monitor of a port showed only what the port's program wrote, not what its links wrote into it. Studio now sends the bytes on, once to each port and never back to the port or the link they came from, so the server and the bus members get the client's bytes, and a monitor shows both directions of the port it watches. One-way links, owners, delays, the listeners of a split and the half-duplex bus keep their rules.
