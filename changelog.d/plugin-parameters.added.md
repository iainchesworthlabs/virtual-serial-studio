**The plugin library can check the settings a user gives to a plugin.** Given what a plugin's manifest declares, it checks each value against its type and limits (range, length, hexadecimal bytes, durations, options and paths), fills in defaults, and refuses unknown, repeated, wrongly typed and missing values, each with the setting's name and a line for a person. A path must be a full path to a file or folder, never a root or a drive and never one with `..` in it. The values are read and written as the `params` of a setup's plugin binding, in the same text the plugin API messages carry. Studio uses it to check the settings of a plugin's instance.
