**The macOS release is now a disk image as well as a tar.gz.** Open `virtual-serial-studio-<tag>-macos-arm64.dmg` and drag `vss_gui.app` onto the Applications link; the image also holds `bin/vss_cli` and the licence texts. It is made by CPack from the `runtime` install component, with the settings of each system in `cmake/packaging/`, and the Release workflow mounts it and runs `vss_cli selftest` and `vss_gui --version` from the mounted image. The image is not signed or notarised yet, so macOS asks you to allow the app on first launch (`docs/releasing.md` says how). The workflow now also calls `tools/macos/sign-and-notarize.sh` when the owner sets `SIGN_MACOS` and adds the certificate and notary secrets; without them it says the package is unsigned and carries on.
