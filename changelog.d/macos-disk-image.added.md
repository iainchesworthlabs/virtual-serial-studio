**The macOS release is now a disk image as well as a tar.gz.** Open `virtual-serial-studio-<tag>-macos-arm64.dmg` and drag `vss_gui.app` onto the Applications link; the image also holds `bin/vss_cli` and the licence texts. The image is not signed or notarised yet, so macOS asks you to allow the app on first launch (`docs/releasing.md` says how).
