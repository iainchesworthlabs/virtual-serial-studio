**The topology canvas has zoom controls.** A small bar in the bottom-right corner of the canvas has zoom out, the current zoom (press it to go back to 100%) and zoom in. Ctrl+wheel and a trackpad pinch zoom about the pointer, Ctrl+plus and Ctrl+minus zoom, and Ctrl+1 returns to 100%; Ctrl+0 still fits everything. The zoom range is now 25% to 400%, so a large setup can be read up close.
