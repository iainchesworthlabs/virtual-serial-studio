**A plugin can ask for the licence file.** The plugin API has three messages for it: `licence.get` asks, `licence.file` answers with the bytes of the best licence file on the computer (up to 64 KiB), and `licence.report` tells the host what the plugin found. They need the engine capability `licence_file`, and a plugin that is not official needs the permission `licence.read`. The API version is now 1.1. Nothing in Studio sends these messages yet.
