**A plugin can ask for the licence file.** The plugin API has three messages for it: `licence.get` asks, `licence.file` answers with the bytes of the best licence file on the computer (up to 64 KiB), and `licence.report` tells the host what the plugin found. They need the permission `licence.read` and the engine capability `licence.file`, and the API version is now 1.1. `docs/plugin-api-reference.md` lists the members and limits. Nothing in Studio sends these messages yet.
