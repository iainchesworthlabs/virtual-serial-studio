**The website describes plugins, licences and updates as release candidate 6 has them.** The Plugins page says that Studio runs plugins, how a plugin is checked and decided about, that Windows confines a plugin and Linux and macOS do not yet, and lists the `vss_cli plugin` and `vss_cli control` commands. The Editions page says how a licence file is imported and that both computers of a seat hold it, and no longer says that Studio runs no plugin. The Privacy, Security, Downloads and Features pages say that the builds do not hold the update keys yet, so Studio makes no update request. The Documentation page links to the plugin, update, licensing and remote control documents.
