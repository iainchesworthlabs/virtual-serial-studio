**Studio behaves like a Windows program.** It never asks for administrator rights when it starts, and Task Manager, Explorer and the UAC and firewall prompts show "Virtual Serial Studio" and the version. `vss_gui.exe` opens no console window when started from the Start menu, Explorer or the sign-in entry (from a terminal it still prints `--version`, `--help` and the `--selftest` result). The Setup check has a **Windows Firewall** row, and the Network endpoint dialog a **Check Windows Firewall for this port** button: they say whether other computers can reach a port Studio listens on and, when no rule allows it, show the rule Studio would add as a `netsh` command. **Allow in Windows Firewall** adds it through Windows' own permission prompt; nothing changes before you press it.
