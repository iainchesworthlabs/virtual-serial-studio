**Studio behaves like a Windows program.** It never asks for administrator rights when it starts; every program carries a manifest saying so, plus a version resource, so Task Manager, Explorer and the UAC and firewall prompts show "Virtual Serial Studio" and the version. `vss_gui.exe` is a Windows-subsystem program, so starting it from the Start menu, Explorer or the sign-in entry opens no console window (started from a terminal it still prints `--version`, `--help` and the `--selftest` result there; use `start /wait` or `Start-Process -Wait` when you need the exit code). The Setup check has a **Windows Firewall** row, and the Network endpoint dialog a **Check Windows Firewall for this port** button: they say whether other computers can reach a port Studio listens on and, when no rule allows it, show the one rule Studio would add (this program, one protocol, one port, your local network) as a `netsh` command. **Allow in Windows Firewall** adds it through Windows' own permission prompt; nothing changes before you press it. **Restart as administrator** explains why Windows will ask before it asks.
