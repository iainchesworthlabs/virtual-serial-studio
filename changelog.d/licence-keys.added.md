**Studio now accepts licences signed with the owner's licence keys.** The release trusts two public keys, `lic-2026-a` and the standby `lic-2026-b`, for licence files and for revocation lists. A licence signed with either is checked on this computer as before; a licence signed with the published test key is still refused. Until now no key was trusted, so every build was the Community edition whatever file was imported.
