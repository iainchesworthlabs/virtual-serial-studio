**A response timing rule set with a misspelt delay is refused with a message instead of crashing the reader.** A delay is one of `fixed_us`, `uniform`, `normal`, `exponential` or `table`. If its only key was none of those (for example `nomlra` for `normal`), the reader went on to look for a key that was not there and crashed. It now reports the key as unknown and stops reading that delay. Rule sets cannot be installed on a port yet, so no running setup was affected.
