**A response timing rule set with a misspelt delay is refused with a message instead of crashing the reader.** A delay is one of `fixed_us`, `uniform`, `normal`, `exponential` or `table`; a key that is none of those (for example `nomlra`) crashed the reader and is now reported as unknown. Nothing in the window or in `vss_cli` loads rule sets yet, so no running setup was affected.
