**A Downloads page on the product site.** The product site is now built with MkDocs on the company's site shell, and its Downloads page is at <https://iainchesworthlabs.com/virtual-serial-studio/downloads/>. It lists the files of the newest release by system, with their sizes and signature links, says how to check a download against the release key, and states what each system needs: x86-64 on Windows and Linux, Apple silicon on macOS, glibc 2.42 or newer on Linux, the test-signed Windows driver and the macOS builds that are not signed. The list of files is taken from the release itself when the site is published, and the site publishes that release's signed update feed unchanged when it has one.
