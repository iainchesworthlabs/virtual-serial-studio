**A port could not be made again until Studio was restarted, and now it can.** If you chose **Recreate ports** (or Studio was opening a lost network connection again by itself) and, while that was still working, you opened a setup in which the same port was different, or removed the port, Studio could still finish opening the old port and keep its COM port or its network connection with no way to reach it. The COM number then stayed taken, so the new setup could not use it, and a device that allows only one connection refused the remade port. Studio now checks that the port is still there before it starts it, and closes the new COM port or connection if it is not.
