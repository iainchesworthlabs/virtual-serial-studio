**Hebrew, Yiddish and Arabic text and byte columns look the same on every system.** Studio now carries three open-licence fonts inside the program: Noto Sans Hebrew and Noto Sans Arabic, used for any Hebrew or Arabic letters the system font cannot draw (for example on a Linux install with no font packages), and IBM Plex Mono for the hex, byte and monitor views, so the columns line up on Windows, macOS and Linux. Text in other languages keeps the system font. No Chinese or Japanese font is included; the Linux packages recommend `fonts-noto-cjk` (Debian) or suggest `google-noto-sans-cjk-fonts` (RPM). The fonts add about 0.6 MB to the program, and their licence texts are installed with the others.
