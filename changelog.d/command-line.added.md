**`vss_cli`, a command line for everything the window does.** It lists serial devices and com0com pairs (`devices`), creates virtual ports (`virtual`, `vport`), shares a device across ports (`share`), joins publishers (`join`), builds a bus (`bus`), bridges transports (`bridge`), watches traffic (`monitor`), runs a saved topology (`run`), records and plays back traffic (`capture`, `play`), answers from a script (`respond`), measures throughput (`bench`) and checks the setup (`permissions check`, `selftest`). Topologies are validated JSON documents, human-editable and the same format the window opens and saves, and the window's **Export as command** turns the current setup into a `vss_cli` command. `vss_cli virtual` keeps its port open until Ctrl-C or SIGTERM, or for `--seconds=N`.
