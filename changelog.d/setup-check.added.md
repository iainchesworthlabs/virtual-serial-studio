**When a port does not work, Studio says why and how to fix it.** **Setup check** reads the facts the platform will give. On Linux it reads the owner group and mode of each serial device and says whether your account is missing the group (with `sudo usermod -aG dialout <you>` and a button that asks polkit for your password and runs just that command), the mode forbids it, or something outside the file permissions refused it; a *Confinement* row explains Flatpak, Snap, AppArmor and SELinux with the override or profile lines to add; a *Firewall* row shows the `ufw` or `firewalld` command that opens a port you listen on. On macOS it explains the Application Firewall (and the commands that fix a mistaken *Don't Allow*), Local Network access and the App Sandbox. **Why is nothing arriving?** runs five checks against the live endpoint state and says "Not checked yet" rather than guessing. The **diagnostic bundle** is a ZIP of the setup, event log, environment and counters that you can attach to a bug report; traffic contents are off unless you tick them and credentials are redacted from every text file. `vss_cli permissions check` prints the same facts.
