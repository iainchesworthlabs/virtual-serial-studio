**`vss_cli` stays alive when it says it does, refuses what it does not understand and reports what it sent.** `run`, `share`, `join`, `bridge` and `loopback` now keep their ports until Ctrl-C, SIGTERM or SIGHUP (a closing terminal), or on Windows until Ctrl-Break or the console window closes, or until `--seconds=N` is over, as `bus`, `virtual` and `capture` did; they used to exit at once. `--seconds` must be 1 or more. An option can be written `--name=value` or `--name value`, except under `control`, `agent` and `permissions`, which take `--name=value` only. An unknown option, a missing value, a value that is not a whole number where one is needed and a stray word give one line on standard error and exit code 2. `--help` and `-h` exit with 0, and `vss_cli --version` prints the version of the build. `vss_cli virtual --com=N` fails when the Windows driver is not there. `vss_cli play` exits with 1 when the port refused a write or stopped taking bytes. `vss_cli devices --json` is now one line of valid JSON and adds each port's `hardware_id`.
