**Adding or closing a program port of a shared device no longer interrupts the link or loses bytes for the other programs.** In the share wizard (**Add another program**), under **Topology → Add a program port**, when you remove a program port, and in Simple mode with **Add a program**, the close button and **Change…** on a shared or attached device or on programs taking turns, Studio now adds the port to the device's link or takes it off in place. The link and the other programs keep running. Before, the link was replaced, so a few bytes in flight could be lost. If a step fails, the setup is as it was.
