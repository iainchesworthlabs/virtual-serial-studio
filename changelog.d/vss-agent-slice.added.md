**`vss_agent`, a first slice of ports that outlive the program that made them.** `vss_agent` keeps one set of ports and links for the user who starts it, and `vss_cli agent` (`status`, `ports`, `create-port`, `remove-port`, `connect`, `write`, `watch`, `stop`) works with them from any number of commands: a port made by one command is still there, and usable, after that command has exited. The two talk over a named pipe (Windows) or a Unix domain socket (Linux, macOS) that only the same user can open; nothing listens on the network. This slice makes loopback ports only, is not in the installers, and Studio does not use it yet. `docs/agent.md` has the design and the decisions still to make.
