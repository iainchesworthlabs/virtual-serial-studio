**Opening a setup, a template or applying the Topology JSON now replaces the setup that is running.** Before, **File > Open**, **File > Setups and templates** and **Apply changes** in the Topology JSON view added the ports and links of the new setup to the ones that were running. The window then showed the new file name with no unsaved mark, and **File > Save** wrote both sets of ports into that file. Applying the JSON of a running setup made a second copy of every port as `name-2`, or was refused when a port used a device or COM number that was already taken. The running setup now becomes the one you opened or applied: a port that is the same in both (same name and same settings) keeps running without a break, and keeps its COM number, and every other port is removed or made new. If the new setup cannot be made, the ports that were running are put back as far as possible and the window says why.
