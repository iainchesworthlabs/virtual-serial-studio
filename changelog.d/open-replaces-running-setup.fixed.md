**Opening a setup, a template or applying the Topology JSON now replaces the setup that is running.** Before, **File > Open**, **File > Setups and templates** and **Apply changes** in the Topology JSON view added the new setup's ports and links to the ones running. **File > Save** then wrote both sets of ports into that file. Applying the JSON of a running setup made a second copy of every port as `name-2`. The running setup now becomes the one you opened or applied. A port that is the same in both (same name and settings) is not touched: it keeps its COM number and keeps running. A link between two such ports is not touched either. Every other port and link is removed and made again, and data on a link meanwhile is lost. This can take up to a minute when Windows has to install a new port. A setup in which two driver ports ask for the same COM number is refused before anything is changed. If the new setup cannot be made, the ports that were running are put back as far as possible (a port that comes back is a new port, without its rules and echo), and the window marks the setup as changed. While the JSON view is applying, Open, New, Setups and templates, Quit and the close button do nothing.
