A simulated device for testing without hardware.

You can link it later from Connect ports.

Studio adds a fixture called modem at 115200 baud, linked two-way to terminal. After it exists you can inject faults and change its line wiring from the Inspector.
What a fixture can simulate

Parity errors, framing errors, overruns, breaks, hang-ups and disconnects. Each is reported as an error event on the port.
