2. Wiring: drag from a handle, drop on a node, choose the link

The wire is dragged from port-1's right handle. Every node shows its handles while a wire is out. The pointer is over tx-sim, which shows the drop highlight. A node that would close a loop would show a red edge instead. On release over tx-sim the link chooser opens; Two-way is the default for Enter.
