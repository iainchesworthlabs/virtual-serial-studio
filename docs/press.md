<h2>In two sentences</h2>
<p>Virtual Serial Studio makes virtual serial ports, shares one serial device with several programs, links ports to each other and shows the traffic on every port. It has a desktop application, a command line for scripts and test jobs, and a Python client for test scripts.</p>
